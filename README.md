# Portfolio
Open index.html in a browser to run it locally. No install needed.
## Publish on GitHub Pages
1. Create a repo (e.g. `yourusername.github.io`), upload all files in this folder.
2. Settings > Pages > Deploy from branch `main` / root.
## Edit
- Links (email, GitHub, etc.): top of js/common.js
- Projects: js/projects.js | Resume: js/resume.js | Languages and tools: js/skills.js
- Add your resume PDF as assets/resume.pdf
